# Wildberries 上架商品数据输入契约与规范 (Input Schema v3.0)

> **版本**：v3.0.0 规范统一版  
> **适用范围**：`listing_engine.py`、`ozon_crawler.py` 以及 AI 助手抓取结果的标准 JSON 契约。  
> **合规基准**：严格遵循 Wildberries《要约》(Оферта) 第 9.2.3 条第 7 款白牌防封合规，以及平台物流尺寸标准。

---

## 一、核心原则与铁律一致性

1. **【100% 白牌脱敏（防封红线）】**：
   - 彻底废除旧版「保留品牌证据链」的危险做法。凡无法提供正规平台官方授权证书的商品，建卡与输入数据中的 `brand` 字段必须留空（`brand: ""`），且属性中不得包含品牌特性 ID，严防商品被打上【被阻止】（Заблокирован）标记甚至封店。
2. **【包装尺寸严格向下取整】**：
   - 彻底废除旧版「向上取整」做法。根据 WB 平台物流测算规则，长宽高必须向下取整到最接近的合法正整数（`math.floor(cm)`，如 24.8cm ➔ 24cm），规避平台按测量公差虚高计费。
3. **【真实毛重与净重规范】**：
   - 商品重量以克（`weight_g`）输入，引擎自动转换为精确到小数点后两位的千克毛重（`weightBrutto = round(weight_g / 1000.0, 2)`）。
4. **【锚定效应大促定价模型】**：
   - 输入 Ozon 原价 `ozon_price`（卢布），引擎自动按目标倍数（如 5 倍）和官方大促折扣（如 50%）反推上架划线原价：
     $$P_{\text{strike}} = \lceil \frac{P_{\text{ozon}} \times \text{倍数}}{1 - \text{折扣率}} \rceil$$

## 二、标准输入 JSON 结构契约

输入可为包含多个商品对象的 JSON 数组 `[ {...}, {...} ]`，或包装对象 `{"products": [...]}`。

```json
[
  {
    "sku": "5557263649",
    "vendorCode": "OZON-5557263649-v1",
    "subjectID": 2012,
    "title": "Беспроводной автомобильный пылесос высокой мощности",
    "ozon_price": 500.0,
    "length_cm": 24.8,
    "width_cm": 15.2,
    "height_cm": 8.0,
    "weight_g": 650,
    "photos": [
      "https://cdn1.ozone.ru/s3/multimedia-1/6850000001.jpg",
      "https://cdn1.ozone.ru/s3/multimedia-1/6850000002.jpg",
      "https://cdn1.ozone.ru/s3/multimedia-1/6850000003.jpg"
    ],
    "description_clean": "Мощный беспроводной пылесос для сухой уборки автомобиля и дома. В комплекте насадки...",
    "characteristics": [
      {"Предмет": 2012},
      {"ТНВЭД": "8508110000"},
      {"Тип пылесборника": "контейнер"},
      {"Тип уборки": "сухая"},
      {"Питание": "от аккумулятора"},
      {"Мощность всасывания (Вт)": "120"}
    ]
  }
]
```

## 三、字段定义与类型约束表

| 字段名 | 类型 | 必填 | 说明与约束 |
| :--- | :---: | :---: | :--- |
| `sku` | string / int | 是 | Ozon 商品原始纯数字 SKU（7~12 位） |
| `vendorCode` | string | 否 | 卖家自编码货号，留空时默认自动生成 `OZON-{sku}-v1` |
| `subjectID` | int | 否 | WB 官方类目 ID，留空时由引擎根据 `title` 智能语义对齐 |
| `title` | string | 是 | Ozon 真实俄文标题，长度 5~60 字符，严禁包含占位符 |
| `ozon_price` | float | 是 | Ozon 参考原价（卢布），用于自动反推大促划线原价 |
| `length_cm` | float / int | 是 | 包装长度（厘米），引擎自动执行 `math.floor` 向下取整 |
| `width_cm` | float / int | 是 | 包装宽度（厘米），引擎自动执行 `math.floor` 向下取整 |
| `height_cm` | float / int | 是 | 包装高度（厘米），引擎自动执行 `math.floor` 向下取整 |
| `weight_g` | int | 是 | 商品带包装总重量（克），用于换算为千克毛重 |
| `photos` | array[string] | 是 | 真实原版主图 URL 列表（1~30 张），严禁假图 |
| `description_clean` | string | 否 | 俄文长描述，自动清洗双重编码乱码，句末自然闭合 |
| `characteristics` | array[object] | 否 | 买家端展示参数矩阵，饱和注入 7~12 项专属核心属性 |

## 四、与旧版契约差异对照

| 对比项 | 旧版试验契约 (v1.0/v2.0) | 现行标准契约 (v3.0) | 修正原因 |
| :--- | :--- | :--- | :--- |
| **品牌合规** | 强行保留品牌并提供证据链 | **100% 白牌脱敏（brand 留空）** | 遵守《要约》第 9.2.3 条第 7 款，彻底杜绝下架封店 |
| **尺寸取整** | 向上取整 (9/6.5/1.8 ➔ 9/7/2) | **严格向下取整 (math.floor)** | 符合测量公差，规避平台高额计费 |
| **价格机制** | 单纯实售倍数或保留原价 | **锚定效应大促定价反推** | 标 10 倍打 5 折实收 5 倍，买家端刺激转化爆单 |
| **图片挂载** | 仅本地单张逐图上传 | **官方云端异步直拉 + 二进制降级** | 挂载速度提升 10 倍，突破网络超时瓶颈 |
