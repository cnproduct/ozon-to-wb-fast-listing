# Wildberries 官方类目展示参数与 maxCount 约束规范

> **版本**：v3.0.0 规范参考  
> **核心原则**：饱和注入 7~12 项展示参数，严格遵守单值/多值约束，杜绝 options 编译失败。

---

## 一、类目展示参数的“饱和注入门槛”

Wildberries 静态编译集群在生成买家端 `options` 网格时，对卖家填写的 `characteristics` 维度有隐性权重阈值：
- 若卖家仅填写 2~3 项通用参数（如仅填“Предмет”和“ТНВЭД”），官方静态切片容易认定为低质量浅层卡片，导致前台参数行展示极度简陋；
- 若卖家饱和注入 **7~12 项专属核心参数**（如功率、容量、材质、清洁类型、配件清单等），卡片不仅在前台展示完整高大上的参数网格，更会在搜索算法中获得更高的筛选权重曝光！

---

## 二、maxCount 约束规范防错铁律

在向 `POST /content/v2/cards/upload` 或 `/content/v2/cards/update` 上送参数时，必须严格遵守属性的 `maxCount` 约束：

1. **单值属性 (`maxCount = 1`)**：
   - 常见属性：功率 (Мощность)、容量 (Объем)、重量 (Вес)、产地 (Страна производства) 等。
   - 规范要求：数组中仅允许传一个值，如 `[{"id": 1234, "value": "120 Вт"}]`。传多个值会被官方接口当场拒收或抛出错误。
2. **多值属性 (`maxCount > 1` 或无限制)**：
   - 常见属性：功效 (Действие)、适用材质 (Обрабатываемая поверхность)、配件清单 (Комплектация) 等。
   - 规范要求：允许上送多个标签或说明，全面覆盖买家搜索关键词。

---

## 三、常见重点类目必填参数对照表

### 1. 吸尘器类目 (SubjectID: 2012 / Пылесосы)
- 建议饱和注入维度：
  - `Тип пылесборника` (集尘类型: контейнер / мешок)
  - `Тип уборки` (清洁类型: сухая / влажная)
  - `Тип питания` (供电方式: от аккумулятора / от сети)
  - `Мощность всасывания` (吸力功率: 120 Вт)
  - `Комплектация` (配件说明)

### 2. 进门地垫类目 (SubjectID: 2317 / Коврики придверные)
- 建议饱和注入维度：
  - `Материал изделия` (材质: ПВХ, резина, микрофибра)
  - `Особенности ковра` (特性: противоскользящий, влаговпитывающий)
  - `Форма ковра` (形状: прямоугольный)
  - `Назначение` (用途: для прихожей, для дома)
